# KasirIn

KasirIn is a responsive retail POS and back-office interface built as a portfolio project for cashier and store operations.

## Highlights

- Mobile-friendly cashier experience
- Sell, orders, customers, shifts, payments, returns, receipts, stock lookup, discounts, loyalty, gift cards, and cashier tools
- Retail back-office dashboard and operational workspaces
- Responsive layouts for desktop, tablet, and phone
- Workspace selection, reusable UX patterns, theme controls, and logout flow
- Modular frontend structure

## Stack

React 19 · TypeScript · Vite · SCSS · React Router · Lucide Icons

## Repository

This repository contains the public portfolio version of KasirIn. The interface uses demo/mock data and is intended to showcase the product flow, frontend architecture, responsive POS UX, and retail back-office design.
